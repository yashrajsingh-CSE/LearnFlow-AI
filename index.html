Can you explain the difference between useState and useReducer? When should I use each one?
2:31 PM
🤖

Great question! Here's the key difference:

useState is perfect for simple, independent state values:

const [count, setCount] = useState(0);

useReducer shines when:

  • State logic is complex (multiple sub-values)
  • Next state depends on previous state
  • You want Redux-like predictability
const [state, dispatch] = useReducer(reducer, initialState);

Rule of thumb: start with useState, switch to useReducer when it gets complicated. 🎯

💡 Pro tip: Understanding useCallback vs useMemo

Spent 2 hours with the AI mentor debugging performance issues and finally understood when to use each. Here's my quick mental model: useCallback is for functions, useMemo is for values. Both only recalculate when dependencies change.

const memoizedValue = useMemo(() => computeValue(a, b), [a, b]);
const memoizedFn = useCallback(() => doSomething(a), [a]);
